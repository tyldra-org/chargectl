# Code of conduct

This project follows the
[Contributor Covenant Code of Conduct](https://www.contributor-covenant.org/).
Its full text is the code of conduct for this project and applies in every
project space: the repository, issues, pull requests, discussions and any
other channel the project runs, and wherever someone officially represents
the project.

## Reporting

Report incidents privately to Yogesh Prasad at yogeshprasad098@gmail.com.
Every report is reviewed, and the reporter's privacy is respected. A
maintainer who is party to a report does not handle it.

## Enforcement

Maintainers follow the Contributor Covenant enforcement guidelines:
correction, warning, temporary ban and permanent ban, chosen by the impact of
the behavior.
